# S Tool 0.1.1

修复内存和隐私问题，建议从 0.1.0 升级。

- 修复 SVG 内嵌位图绕过像素和内存预算的问题：渲染前进行 XML 预检，拒绝含图片元素的 SVG（包括 Base64、外部图片及带命名空间前缀的图片元素）。请使用纯矢量 SVG。
- 拒绝含 DTD 的 SVG，避免实体或外部声明进入渲染库。
- 移除 AndroidSVG 的内容日志调用，开发版和正式版均生效；源码查看和显式复制保持可用。
- 保留现有取色、水印、后台会话保留和折叠屏布局行为，不增加后台服务或自启动。

支持 Android 9 及以上。下载 `S-Tool-0.1.1.apk`，可直接覆盖安装 0.1.0，沿用同一发布签名。`SHA256SUMS.txt` 用于校验下载文件。
