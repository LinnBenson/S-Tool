# S Tool 0.1.0

首个正式版本，支持 Android 9 及以上。

- SVG 查看器：缩放、平移、全屏、源码查看与复制，以及 PNG 导出。
- 取色器：原始像素取色、放大镜、逐像素微调，HEX / RGB 独立复制。
- 水印工具：全图平铺文字，支持文字、字号、横竖间隔、颜色、不透明度和角度；自动复用最后一组有效参数。
- 浅色/深色主题、宽屏分栏、书本式及桌面式折叠布局。
- 三个工具的选择与导出/复制按钮统一移至右上角，以图标显示，增加工作区空间。
- 新版科技感 S 图标，深墨蓝背景与均匀留白。

离线处理，不保存输入图片或文件历史，无自启动和后台服务。仅在本机保存主题及最后一组水印参数。

下载 `S-Tool-0.1.0.apk` 安装；使用 `SHA256SUMS.txt` 校验文件。APK 使用正式发布密钥签名。

已知限制：SVG 以静态渲染为主，不支持全部浏览器 SVG 特性；图片受像素和内存预算限制；折叠屏布局已通过姿态注入测试，尚未完成真实铰链设备验证。
